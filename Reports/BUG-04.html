Title *
Two discount codes can be applied to the same cart
Reporter *
Dalii · QA
Bug Overview
Summary *
WELCOME10 and FIVEOFF can both be applied to the same cart and their discounts add up.
Module / Class *
POST /carts/{id}/promo · apply-promo handler (tests/test_promo.py)
Category *
Promo codes
Layer *
Backend / API
Technical Environment
Environment
Local server (node server.js, port 3002)
Platform
REST API (Node.js)
Test Duration
stc-promo-09: 17 ms · stc-promo-10: 19 ms
Defect Details
Precondition *
Server freshly reset. Cart c1 with 2 Amber Candles (subtotal 3990).
Steps to Reproduce *
WELCOME10 then FIVEOFF
  1. curl -X POST http://localhost:3002/reset
  2. curl -X POST http://localhost:3002/carts
  3. curl -X POST http://localhost:3002/carts/c1/items -H "Content-Type: application/json" -d '{"productId": 1, "quantity": 2}'
  4. curl -X POST http://localhost:3002/carts/c1/promo -H "Content-Type: application/json" -d '{"code": "WELCOME10"}'
  5. curl -X POST http://localhost:3002/carts/c1/promo -H "Content-Type: application/json" -d '{"code": "FIVEOFF"}'
  6. curl -X GET http://localhost:3002/carts/c1
Expected Result *
  • The second code returns 409.
  • promoCodes is ["WELCOME10"], discountCents 399.
Actual Result *
  • The second code returns 200.
  • promoCodes is ["WELCOME10","FIVEOFF"], discountCents 899, totalCents 3581.
Error / Stack Trace
POST /carts/c1/promo -> HTTP 200
{"id": "c1", "status": "open", "promoCodes": ["WELCOME10", "FIVEOFF"], "items": [{"productId": 1, "name": "Amber Candle", "unitPriceCents": 1995, "quantity": 2, "lineTotalCents": 3990}], "subtotalCents": 3990, "discountCents": 899, "shippingCents": 490, "totalCents": 3581}

GET /carts/c1 -> HTTP 200
{"id": "c1", "status": "open", "promoCodes": ["WELCOME10", "FIVEOFF"], "items": [{"productId": 1, "name": "Amber Candle", "unitPriceCents": 1995, "quantity": 2, "lineTotalCents": 3990}], "subtotalCents": 3990, "discountCents": 899, "shippingCents": 490, "totalCents": 3581}
Impact *
Discounts stack without limit between discount codes, so every customer who knows two codes pays less than the shop allows.
Classification
Severity *
Critical Money is wrong and the shop loses revenue on purpose-built carts.
Priority *
P1 fix order 4 of 10

Recommendation
Suggested Fix *
Before adding a code, return 409 when the cart already holds a discount code and leave the cart unchanged. (SUMMER25 could not be checked in a normal run because it is expired.)

Possible cause: There is no check for an existing discount code when a code is added.
Spec reference: SPEC §5: “A cart holds at most one discount code; applying a second one is refused with 409 and the cart does not change.”
